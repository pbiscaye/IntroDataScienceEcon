# Introduction to Data Science for Economists

This page provides access to teaching materials for my **Introduction to Data Science for Economists** course at the Université Clermont Auvergne.

The course introduces tools and approaches from data science that are useful for applied economic research, with applications in Python.

## Latest complete course materials

### [2026 course materials](https://github.com/pbiscaye/IntroDataScienceEcon2026)

The 2026 version is currently the most recent complete version of the course.

Topics covered include:

1. Introduction to data science and Python/Jupyter setup and basics
2. Research reproducibility and Python tabular data wrangling
3. Generative AI; Python data exploration and visualization
4. Accessing and working with different data sources: web APIs, web scraping, and Google Earth Engine
5. Introduction to spatial data and remote sensing
6. Introduction to machine learning, with a focus on supervised learning
7. Introduction to text analysis and natural language processing

The course repository includes lecture materials, example code and notebooks, exercises, setup instructions, and supporting files.

## Using these materials

These materials are publicly available for students, instructors, researchers, and others interested in learning or teaching data science for applied economics.

Materials will be updated each year. For the most up-to-date complete set of materials, I recommend using the latest course version linked above. 

If you use or adapt the course materials, please refer to the citation information provided in the corresponding course repository.
